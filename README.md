### 📖 About Me

- 🎓 B.Sc. in Electronics, M.Sc. in Telecommunications Systems — transitioned into software development to build things people actually use.
- 📱 Currently focused on **native Android development** with **Kotlin** and **Jetpack Compose**.
- 🏗️ I care about clean architecture — MVVM, Hilt, Room, WorkManager — and building apps that feel right for **Persian-speaking users** (RTL layouts, Jalali calendars, Persian text handling).
- 🌍 Based in Qazvin, Iran 🇮🇷
- 📡 CCNA certified, with a networking background that still sneaks into how I think about systems.
- 💬 I write and share technical content in Persian for local communities, and in English for global visibility.

### 🚀 Featured Projects

**[TaskFlowChain (taskflow-bot)](https://github.com/mnfarzaneh/taskflow-bot)**
A Telegram-based task management bot with chain-based (sequential) task unlocking, built with Flask + Supabase, deployed on PythonAnywhere.

**[TaskFlow](https://github.com/mnfarzaneh/TaskFlow)**
A Persian-first Android task manager built from scratch with MVVM + Clean Architecture, Hilt, Room, WorkManager, and Jetpack Compose. Features a custom Jalali calendar, drag-and-drop reordering, a Home Screen Widget (Glance), and a custom Persian DatePicker.

**[SolarChef](https://github.com/mnfarzaneh/solalrChef)**
My first published Android app on Cafe Bazaar — a solar oven recipe app with a glassmorphism UI, Canvas-based animations, and a full Compose + Room + Hilt + MVVM stack.
