### 🚀 Featured Projects

**[SolarChef](https://github.com/mnfarzaneh/solarChef)** · **v1.1.1** · [Available on Cafe Bazaar](https://cafebazaar.ir/app/com.mnfarzaneh.solalrchef)

My first published Android app, now a Persian-language cooking companion for saving recipes, scaling ingredients, and following cooking steps. Built with **Kotlin, Jetpack Compose, Room, Hilt, and WorkManager**, with a dark and gold theme and light-mode support.

- Create recipes with photos, ingredients, equipment, and cooking steps; organize them with custom categories and favorites.
- Adjust ingredient quantities by servings or by an ingredient amount, and follow recipes in a dedicated cooking view.
- Back up and synchronize personal recipes through an account, while keeping saved recipes and ingredient calculations available locally.
- Extract structured recipes from text with AI assistance, review them before saving, and read shareable cooking articles.
- Version **1.1.1** fixes a database migration for users upgrading from older schemas, preserving their saved recipe data.

The linked repository contains the **Android app's source code**. Separately maintained services use **Kotlin / Ktor and PostgreSQL** for accounts and content, **ArvanCloud object storage** for images, and **Python / Flask with Gemini** for recipe extraction, alongside web article pages and an admin panel.
